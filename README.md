# 🌌 StellarSnap

StellarSnap is an independent, ad-free way to explore NASA's Astronomy Picture of the Day (APOD).

🔗 Live site: [stellarsnap.space](https://stellarsnap.space)

## ✨ Features
- 🔭 Every APOD since 16 June 1995, more than 11,000 pictures, browsable by year, month and day
- 📖 Glossary of around 200 astronomy terms, linked from the daily explanations
- 🪐 Orbit Simulator: pick a planet, set altitude and speed, and launch a satellite to see the orbit it takes
- ⏱️ Time Dilation Simulator: compare how fast clocks run near planets, stars and black holes
- 📝 Articles: longer reads on space, time and the universe
- ⭐ Save favorites with a free account
- ✉️ An occasional email when something new ships
- 📱 Responsive, dark interface with no ads

## ⚙️ Tech Stack
- Framework: Next.js 15 (App Router, Server Components), React 19, TypeScript
- Styling: Tailwind CSS v4
- Data: PostgreSQL 17 via Prisma
- Accounts: Better Auth on the site's own database
- Email: Brevo
- Analytics: Cloudflare Web Analytics (cookieless)

## 🚀 Deployment
- Self-hosted on a Hetzner VPS with Docker Compose, behind Cloudflare
- Deployed with GitHub Actions

## 🙋 About
StellarSnap began as a personal curiosity project and is built and maintained by one developer. It has no ads and no paywall.

StellarSnap is listed in the Modern Formats section of [NASA's About APOD page](https://science.nasa.gov/apod/apod-about/). It is not affiliated with or endorsed by NASA.
